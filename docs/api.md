# Classic Games Arcade — REST API Specification (sacga/v1)

This document specifies the REST API routes, headers, authentication model, and rate limits for the Classic Games Arcade platform. All endpoints reside under the `sacga/v1` namespace.

---

## Authentication & Headers

Requests are authenticated using a combination of WordPress user sessions, secure guest cookie tokens, and client identifiers.

### Required Headers
*   **`X-WP-Nonce`**: Required for logged-in WordPress users to prevent Cross-Site Request Forgery (CSRF) on state-changing write operations.
*   **`X-SACGA-Guest-Token`**: Holds the cryptographically signed guest cookie/HMAC token for non-logged-in players.
*   **`X-SACGA-Client-ID`**: A persistent UUID generated by the frontend and stored in browser `localStorage`. Used for seat rejoining and session validation.

## REST Endpoints Directory

### 1. Room Administration & Lobbies

#### A. Create Matchroom
*   **Route:** `POST /sacga/v1/room`
*   **Parameters:**
    *   `game_id` (string, required): The ID of the target game (e.g., `checkers`, `spades`).
    *   `display_name` (string, optional): Custom nickname for guest creator.
*   **Description:** Creates a new matchroom and auto-joins the creator at Seat 0 (Host seat).
*   **Rate Limit:** 10 requests / 5 minutes.

#### B. Join Matchroom
*   **Route:** `POST /sacga/v1/room/{room_code}/join`
*   **Parameters:**
    *   `display_name` (string, optional): Custom nickname for guest joining the lobby.
*   **Description:** Joins an open room lobby at the first vacant seat.
*   **Rate Limit:** 10 requests / 5 minutes.

#### C. Leave Matchroom
*   **Route:** `POST /sacga/v1/room/{room_code}/leave`
*   **Description:** Relinquishes your seat and leaves the matchroom lobby. If the room is empty, it is deleted automatically.
*   **Authorization:** Must be a registered player in the target room.

#### D. Get Room Lobby Data
*   **Route:** `GET /sacga/v1/room/{room_code}`
*   **Description:** Returns general room metadata, player seat mappings, and connection statuses. Private client identifiers and guest tokens are automatically stripped from the response players array.
*   **Authorization:** Open to the public.

### 2. Host Administrative Actions (Host-Only)

The "Host" is dynamically promoted to the active seated player with the lowest seat index (usually Seat 0 creator).

#### A. Add AI Opponent
*   **Route:** `POST /sacga/v1/room/{room_code}/ai`
*   **Parameters:**
    *   `difficulty` (string, optional): Default `'beginner'`, or `'intermediate'`, `'expert'`.
*   **Description:** Fills the next vacant seat with an automated AI bot.
*   **Authorization:** Restricted to the room Host.

#### B. Kick Player or AI
*   **Route:** `POST /sacga/v1/room/{room_code}/kick/{seat_position}`
*   **Description:** Forcefully evicts a player or AI bot from the room, freeing up their seat. Kicked human clients auto-redirect to the lobby upon their next polling check.
*   **Authorization:** Restricted to the room Host.

#### C. Launch / Start Game
*   **Route:** `POST /sacga/v1/room/{room_code}/start`
*   **Description:** Transitions the room status from `lobby` to `active` and initializes the game's state machine.
*   **Authorization:** Restricted to the room Host. Requires room player counts to meet the game's minimum player threshold.

### 3. In-Game State & Play Mechanics

#### A. Fetch Live Game State
*   **Route:** `GET /sacga/v1/game/state/{room_code}`
*   **Query Parameters:**
    *   `etag` (string, optional): Used for polling synchronization. If the state matches the provided etag, the server returns 304 (or `changed => false`) to save bandwidth.
*   **Description:** Returns the complete public state-machine JSON vector of the game.
*   **Authorization:** Open to the public (supports spectator views).

#### B. Submit Move
*   **Route:** `POST /sacga/v1/game/move/{room_code}`
*   **Parameters:**
    *   `move` (array/object, required): Game-specific move payload (e.g. piece coordinates, card discards).
    *   `etag` (string, required): The etag of the state on which the move is being made. Used to enforce Compare-And-Swap (CAS) state version locking.
*   **Description:** Validates and executes a player move.
*   **Rate Limit:** 60 requests / 1 minute (move-spam throttling).
*   **Authorization:** Restricted to the seated player matching the current turn, or a simultaneous phase participant.

#### C. Forfeit Match
*   **Route:** `POST /sacga/v1/game/forfeit/{room_code}`
*   **Description:** Voluntarily forfeit the match. Calculates winners dynamically (team-aware partnerships for Spades; otherwise remaining human/AI seats).
*   **Authorization:** Restricted to registered players in the room.

---

### 4. Connection & Session Recovery

#### A. Rejoin Active Check
*   **Route:** `POST /sacga/v1/rejoin-check`
*   **Parameters:**
    *   `client_id` (string, required): The UUID of the rejoining client from `localStorage`.
    *   `game_id` (string, required): The ID of the game being checked.
*   **Description:** Validates if a disconnected client was recently registered in an active room.
*   **Security:** Cryptographically verifies that the caller's secure guest token or user ID matches the registered owner of the seat associated with the `client_id` before returning room details.
